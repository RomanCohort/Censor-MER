# 职校学生反馈收集方案

## 背景
暑假期间招募5-10名职校学生，日薪100元，进行微表情生成质量评估。

## 成本预算

| 项目 | 数量 | 单价 | 总价 |
|------|------|------|------|
| 学生日薪 | 10人×2天 | 100元 | 2000元 |
| 电脑使用 | 10台 | 免费 | 0元 |
| 零食饮料 | 10人×2天 | 20元 | 400元 |
| **总计** | | | **2400元** |

## 工作内容

### 任务1：视频质量评估（主要）
- 观看生成的微表情视频
- 判断表情类别是否正确（微笑/惊讶/厌恶/压抑）
- 评分：自然程度1-5分
- 标注问题：运动太大/太小/不自然/其他

### 任务2：对比评估
- 同时观看两个版本生成的视频
- 选择更好的一个
- 说明理由

### 任务3：自由反馈
- 描述看到的表情
- 指出明显问题

## 工作流程

### 第一天上午（9:00-12:00）
- 培训：什么是微表情
- 培训：如何使用评估系统
- 练习：评估10个样本视频
- 讨论：统一评分标准

### 第一天下午（14:00-18:00）
- 正式评估：每人100个视频
- 中场休息：统一答疑
- 继续评估

### 第二天（9:00-18:00）
- 对比评估：每组视频二选一
- 自由反馈
- 总结讨论

## 数据收集

### 评估界面
使用Web界面（Gradio）：
- 视频播放器
- 表情类别选择（4选1）
- 自然程度评分（滑块1-5）
- 问题勾选（多选）
- 文字描述（可选）

### 数据格式
```json
{
  "video_id": "gen_001_happiness",
  "evaluator_id": "student_01",
  "predicted_emotion": "happiness",
  "is_correct": true,
  "naturalness": 4,
  "problems": ["运动稍大"],
  "comments": "整体不错，笑容有点夸张",
  "timestamp": "2026-07-15 10:30:00"
}
```

## 质量控制

### 培训测试
- 先评估10个已知答案的视频
- 正确率>80%才上岗

### 一致性检查
- 随机抽取20%视频二次评估
- 计算评估者间一致性

### 异常检测
- 评估时间<10秒：可能敷衍
- 全部选同一选项：可能敷衍
- 自动标记并复查
